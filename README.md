# servoPico
servoPico for pico or PicoW

picoを使ったサーボー制御基板。最大6台のサーボを制御できます。また温度、湿度センサー、LED、SWが付いているので、色々なアプリケーションへの応用が可能です。<br>

<<概要>><br>
　Raspberry Pi picoを使ったサーボー制御基板<br>
　最大6台のサーボを制御できます。<br>
　センサー　温度、湿度センサー、明暗センサー<br>
　スイッチ　2個<br>
　LED     2個<br>
　サンプルプログラムはpythonで、すべてのソースプログラムを開示いたします。<br>

・LEDの色等指定はできません。<br>
・部品の仕様が変わる場合があります。<br>
・基板のバージョンが変わる場合がありますが、機能等に違いはありません。<br>
・ラズパイは付属しません。<br>

<<使用方法>><br>
インストールについては、インストール文書に従いインストールを行ってください。<br>
mainプログラムはセンサー関係のみの動作です。サーボ関係の動作はservo_zerp.pyとservo_demo.pyを参考に作ってください。<br>

<<動作環境>><br>
2026/06/06 pico,picoWにてファームウェア(RPI_PICO_W-20260406-v1.28.0.uf2)　で動作確認ok<br>
